本工具用于 **《杀戮尖塔2》(Slay the Spire 2)** PC 版与安卓移植版之间的存档双向同步。支持同步进阶等级、卡牌解锁、对局历史战绩以及当前正在进行的残局。

### 第一步：准备工作

1. **手机开启调试**：进入手机 设置 -> 关于手机 -> 版本号，连续点 7 次。返回 系统设置 -> 开发者选项，开启 **USB 调试**。
2. **连接电脑**：用数据线连接手机，手机弹出“允许USB调试”时，勾选“始终允许”并点确认,之后选择仅充电即可,如果失败可改成传输文件。

------

### 第二步：同步操作

#### 1. 电脑存档 -> 同步到手机 

- 确保电脑上已关闭游戏。
- 运行 sts2 sync.cmd，输入数字 1。
- 同步完成后，直接打开手机版游戏即可看到最新的进度。

#### 2. 手机存档 -> 同步到电脑

- 确保手机上已杀掉游戏后台，电脑上未运行游戏。
- 运行 sts2 sync.cmd，输入数字 2。
- **关键点**：同步完成后首次启动 Steam 版游戏，如果弹出 **“存档冲突”** 提示，请务必选择 **【上传本地存档到 Steam 云端】**，否则你的努力会被云存档覆盖！

------

### 第三步：恢复备份

如果你发现同步错了，或者存档损坏了：

1. 输入数字 3 (电脑) 或 4 (手机)。
2. 根据显示的**时间戳**找到你想找回的那份存档。
3. 输入对应的序号，一键救回。

------

### 注意事项

- **关闭游戏**：同步前请务必确认**两端的游戏都已经关闭**，否则可能导致存档损坏或同步失败。
- **设置保护**：本工具默认**不同步游戏设置**（如音量、亮度、触控缩放），以免造成设备显示异常。
- **PC 路径**：工具会自动识别 Steam 默认安装路径下的存档。
