- # STS2 Sync

  用于《杀戮尖塔 2》PC 版与安卓移植版之间的存档双向同步。

  支持同步进阶等级、卡牌解锁、对局历史战绩以及当前正在进行的残局。

  ------

  ## 准备工作

  ### 1. 开启手机 USB 调试

  设置 → 关于手机 → 连续点击**版本号** 7 次 → 返回 → 开发者选项 → 开启 **USB 调试**

  ### 2. 连接电脑

  1. 用数据线连接手机和电脑
  2. 手机弹出"允许 USB 调试"时，勾选**始终允许**并确认
  3. USB 用途选择**仅充电**（如连接失败可改为传输文件）

  > **遇到 `no devices/emulators found`？** 这是手机和电脑之间 ADB 连接失败，常见原因：
  >
  > - USB 调试未开启，或未点击授权弹窗
  > - 数据线不支持数据传输（纯充电线）
  > - 驱动未安装，Windows 通常自动安装，失败请到手机品牌官网下载
  > - 大多数手机需在开发者选项中额外开启**允许仅充电模式下进行调试**

  ------

  ## 同步操作

  ### PC → 手机（选 1）

  1. 关闭电脑上的游戏
  2. 运行 `点我启动点我启动.bat`，输入 `1`
  3. 同步完成后直接打开手机版游戏即可

  ### 手机 → PC（选 2）

  1. 手机结束游戏后台，电脑上未运行游戏
  2. 运行 `点我启动点我启动`，输入 `2`
  3. 同步完成后启动 Steam 版，若弹出**存档冲突**提示，选择**上传本地存档到云端**，否则手机进度会被覆盖

  ------

  ## 恢复备份

  每次同步前工具会自动备份，最多保留 10 份。

  | 选项 | 说明         |
  | ---- | ------------ |
  | `3`  | 恢复电脑存档 |
  | `4`  | 恢复手机存档 |

  根据时间戳选择对应序号即可还原。

  ------

  ## 注意事项

  - **同步前关闭游戏**，两端都要关，否则可能导致存档损坏
  - **设置不同步**，字体、分辨率、缩放等设备设置保持独立
  - **路径自动识别**，工具会自动找到 Steam 默认路径下的存档，无需手动配置
